## 核心数学与接口

体素方案中，令源 OCT 为 `c`、目标 OCTA 为 `y`：

```text
x_t = (1-t)c + t*y
u   = y-c
v   = UNet3D(concat(x_t, c), t)
loss = mean((v-u)^2)
```

小波方案将 `c`、`y` 变换到单层三维正交 Haar 的八个子带，在系数域构造相同直线路径并学习速度。
推理从纯 OCT 或其 Haar 表示开始；固定最初 OCT 条件，从 t=0 向 t=1 积分。

审阅时请核对：条件是否固定，速度符号和时间方向是否一致，子带与空间轴是否对应，
系数域是否保留有符号值，奇数体积补边与逆变换是否一致，滑窗是否在统一网格上融合。
等权正交 Haar 系数 MSE 与体素速度 MSE 的数学关系，应结合具体尺寸和边界处理核对。

## 结合结果要回答的问题

1. **训练路径与自由生成是否一致？** 对含有真实目标信息的插值状态，低速度误差是否代表模型具备纯 OCT 起点能力？
   可以设计 t=0、早期 t 和自由积分的固定训练/验证体块对照；应将这种担忧表述为待验证假设。
2. **MAE、PSNR 与投影结构为何出现权衡？** 请将体积误差、强度分布、分层投影相关性和可见血管结构分别讨论。
   固定窗图与独立 P99 增强图的显示目的不同。
3. **如何做公平消融？** 当前结果为 100 对 200 轮、单 seed。需要明确总更新预算、验证选择次数、参数量和原始空间感受野。
   首页 200/200 轮命令只是运行示例，不是本包已经完成的结果。
4. **数据与评价是否支持结论？** 代码中的检查可审查；真实配准、患者映射和原始数据内容不能仅靠这些导出表证明。
   真实层边界只用于推理后评价，不能将其视为仅用 OCT 得到的额外模型输出。
