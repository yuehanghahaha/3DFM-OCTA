**OCT→OCTA 三维生成：方案审查与可执行改进建议**

核对日期：2026-10-04。依据：当前本地 FlowOCT 源码、正式论文/作者仓库、`E:\研一\OCTA-500数据集` 的目录与代表性数据检查。本文是立项与实现审查，不是训练结果；没有运行新的真实数据模型训练，也没有验证 A100 80GB 上的性能。

**1. 总体判断**

研究方向可行，原方案不宜原样执行。可以实现“带血管结构条件和结构损失的三维 Flow Matching”，但目前不能支持“真实三维血管拓扑受到保证”“一定降低显存”“一定优于所有 SOTA”或“按这四个贡献即可达到 TMI/JBHI”的结论。

最严重的不是少一个模块，而是基线认识、监督来源、拓扑含义和验证协议同时存在问题。直接照原文实现，很可能花费数月得到一个能训练的复杂网络，却无法解释增益来自哪里，也无法证明患者的微血管是真的。

| 问题 | 判断 | 对研究的影响 |
|---|---|---|
| OCT→OCTA 配对体生成 | 可研究 | 存在既有工作和数据基础 |
| FlowOCT 是 VQVAE + 原生 3D UNet | 与当前代码不符 | 主干替换、显存和基线叙事都要重写 |
| 原 FlowOCT 只有像素损失 | 错误 | 已有结构关注、深度对比、投影约束 |
| 当前数据提供完整 3D 血管拓扑真值 | 不成立 | 不能直接开展原定强监督三维拓扑评价 |
| 将离散码本索引直接送入连续 ODE | 定义错误 | 必须区分索引、连续 embedding 和离散生成 |
| 3D VMamba 比 3D UNet 省显存 | 待测假设 | 线性复杂度不推出这个结论 |
| 条件拼接保证拓扑不变 | 不成立 | 属于条件化与软约束，缺少数学保证 |
| 四组消融分离三个因素 | 不充分 | 拓扑分支与拓扑损失捆绑，压缩器也混入 |
| A100 80GB 支撑 patch/潜空间实验 | 合理可行 | 全分辨率多分支训练是否可行仍需 profiling |
| 以此直接承诺一区顶刊或 SOTA | 不可承诺 | 取决于新颖性、效果、可重复性和临床证据 |

我建议保留 Flow Matching 和血管保真问题，把 Mamba 降为候选主干，把 VQVAE 降为候选压缩器，首先建立可信的评价链路。论文的科学问题应是：**结构约束能否减少错误血管和错误缺失，同时保留真实无灌注区？**

此次遍历了 500 例 OCT/OCTA 病例目录并比较切片名称/数量；每个子集抽取首、中、末病例的首、中、末切片读取像素；每类标签抽检 10001、10301；读取两份病例表。未逐像素解码全部约 36 万张切片，未完成全库配准检查。

| 病例范围 | 10301–10500 | 10001–10300 |
| 每例预期 B-scan 数 | 304 | 400 |

**发现实际损坏病例：10294。** OCTA 目录缺少 `253.bmp`，存在 `253.bmp.truncated`，大小 49,152 bytes。Pillow 能读图头，但完整解码报告 `OSError: image file is truncated`。不能改回扩展名就当作恢复，也不能在测试真值中插值一张后不披露。优先从原始压缩包或数据来源恢复；若不能恢复，预先制定全方法一致的排除规则，并报告实际测试样本数。按常见生成编号划分，它处于测试集。

标签目录实际为 `Label/Label`，其中每类 500 个文件：

| 标签 | 抽检表示 | 能支持什么 |
|---|---|---|
| GT_LargeVessel、GT_Artery、GT_Vein | 二维二值 BMP | en-face 血管、动静脉评价 |
| GT_Capillary | 二维二值 BMP | 需核对类别语义的投影血管评价 |
| GT_CAVF | 二维 BMP，类别值 0–4 | 多类投影评价，必须核对类别映射 |
| GT_FAZ | 二维二值 BMP | FAZ 投影区域评价 |
| GT_FAZ3D | MATLAB v7.3，`FAZlabel` | 三维 FAZ 区域，不是三维血管树 |
| GT_Layers | `Layer` 为 6×304×304 或 6×400×400 | 六层边界坐标，不是血管分割体 |

FAZ3D 的 HDF 存储维度为 304×304×640 / 400×400×640；MATLAB 与 HDF/Python 的轴约定必须核验，不能直接根据 shape 配对。

还有一个容易漏掉的语义问题：抽检的 `GT_Capillary` 完全包含 `GT_LargeVessel` 的阳性像素。例如 10001 的大血管 13,243 个像素全部位于 `GT_Capillary` 内。因此不能仅看文件夹名称就宣称其代表“去除大血管的纯毛细血管真值”。应核对 CAVF 类别定义，明确评价全血管、毛细血管区、大血管区的规则。

数据集论文还说明，毛细血管标签包含模型辅助生成与拓扑优化步骤。它是有用的标准基准，但不能当作无误差、全部逐体素人工勾画的微血管真值。这会影响拓扑结论强度，最好增加独立专家复核的小 ROI。[OCTA-500 数据论文，第 3.5 节及补充说明](https://arxiv.org/pdf/2012.07261)。

病例表显示：3 mm 的 200 例中 NORMAL 为 160 例；6 mm 的 300 例中 NORMAL 为 91 例，OTHERS 为 96 例。因此两个子集的差异同时包含视场、分辨率和病例构成，不能将跨子集性能变化全部归因于分辨率。

病例表只有 ID、Sex、OS/OD、Age、Disease 等字段。不能凭不同 scan ID 就推断不存在同一人的双眼或重复扫描；需依据原始数据说明和可得受试者对应关系确认独立性，缺少映射时如实报告。

**4. 轴、投影和预处理不是小细节**

原始 BMP 的 640 维是 B-scan 轴向像素方向，而文件序号是扫描方向。`pack_pair.py` 自身不推断物理轴、不配准、不裁剪，不等于完整预处理规范。

我分别对 10301 和 10001 做了原始 OCTA 体投影检查：按切片堆叠后沿数组 axis=1 求均值，再转置二维结果，与提供的 FULL 投影相关系数分别约 0.9989、0.9967。这表明至少这两个样本存在明确的投影转置关系。灰度并不直接相等，设备提供的投影有不同的强度处理；不能拿原始均值和设备投影直接算 MAE 后认定生成误差。

ILM–OPL 投影比较也支持上述方向，但 0/1 索引边界偏移在两个样本上的最优结果不一致。这只是几何诊断，不能据此按患者挑最优偏移。必须从标签约定确定统一规则，再对多例做叠加检查。

推荐记录一个明确的 tensor 契约，例如 `[B,C,Z,H,W]`，同时保存原始扫描轴顺序、面内转置、spacing、层边界、裁剪起点和逆变换。若使用 `[Z,scan,lateral]`，原始体转换为 `(1,0,2)`；若采用与设备投影一致的面内排列，可能选择 `(1,2,0)`。两种都可用，关键是 OCT、OCTA、层边界和二维标签同时一致转换。

必须处理：

- 3/6 mm 横向采样不同，轴向和横向各向异性明显，旋转、骨架长度和容差用物理尺寸或明确的像素规范。
- 不任意翻转视网膜深度方向；常用增强优先限制在面内，且对配对图、标签、层边界同步。
- 标签用合适的离散插值，图像用连续插值；旋转和缩放本身可能切断细血管，先评估增强损伤。
- 固定绝对 Z 裁剪可能截掉曲率大或病变抬升的视网膜。采用从 OCT 可获得的解剖区域定位，并报告覆盖率。
- 若测试生成依赖人工层边界或目标 OCTA 生成的 ROI，它就是额外输入，不能称为仅 OCT 推理。人工层边界用于共同的离线评价可以，但需说明。
- 训练可以用目标标注采样前景 patch；推理必须覆盖全体/约定 ROI，不能利用测试真值定位“好看的 patch”。
- native/en-face 高分辨率应尽可能保留；不应为套用 256³ 代码把 3/6 mm 任意变成同一几何空间。
- 强度规范统一；避免每张预测和真值独立 min-max 后隐藏灰度误差。图像计算前转浮点，避免 uint8 差分溢出。

**5. 当前所谓“3D 拓扑先验”没有定义完整**

从 OCT 输入预测血管先验是可实现的辅助任务，但问题不是写一个 3D UNet 就结束：

1. 监督目标是什么？只有 FM/重建损失时，中间特征未必是血管，更未必是拓扑。
2. 若输出概率图，哪一维代表血管概率？有无 sigmoid、类别定义、校准和独立评价？
3. 有二维投影监督不代表血管在三维深度上的位置已确定。不同三维血管体可以产生相同 MIP。
4. 从目标 OCTA 提取伪标签可以用于训练，但必须标为伪标签。阈值/血管滤波会继承噪声、投影伪影和低流速漏检。
5. 同一个伪标签算法既监督又给“真值”，无法独立证明医学真实性。
6. 下采样后的概率图可能丢失一像素宽血管。与 latent 对齐的粗图不天然保留原分辨率拓扑。
7. 将特征拼接到向量场只增加条件信息；网络可以忽略它，也可以放大错误。

端到端训练允许联合优化，不能消灭错误传播。“不是两个网络堆叠”不是学术证明。应通过不提供先验、随机打乱先验、直接有标签辅助头但不反馈生成器等对照，判断它是否提供了患者特异的信息。

此外，VQVAE 先预训练再冻结，本来就是阶段式训练。准确表述是“预训练并冻结压缩器后，联合优化生成器和先验分支；推理仅使用 OCT”，不能宣称整套系统从零单阶段端到端。

**6. “更连通”不是正确的医学目标**

OCTA 主要反映运动对比/灌注相关信号；结构 OCT 与动态血流信息不是同一观测。单次结构强度体不能保证唯一确定患者微血管灌注。可学习相关性，但不能把生成图当作测得的血流。

真实无灌注、毛细血管丢失和异常新生血管可能是关键病变。若目标是最少连通分量、最少断点或最光滑骨架，模型可能：填平缺血、跨 FAZ 搭桥、把不同深度血管粘连，或删除病理性分支以使图更规则。

应同时考核：血管召回、血管精度、错误桥接、无灌注区内假阳性，以及病变分层表现。正常外层无血管这一规律也不能作为对所有 CNV 病例的硬约束。

2026-08-16 的预印本 *In Defense of OCTA* 已利用冻结真实 OCTA 分割器讨论重建分数与毛细血管下游用途之间的差距。它测试特定模型，不能证明所有方法都失败，但你的动机和评价设计需要回应这类证据，不能再称“首次关注医学结构指标”。[预印本](https://arxiv.org/abs/2608.15626)。

**7. Flow Matching 和潜空间的数学问题**

连续 FM 的状态需要处于可以定义插值和速度的向量空间。VQ 的码本**索引**是类别，不具有编号之间的物理距离。将索引 2、8 做线性插值，没有合理的生成含义。

可选实现：

- 在 codebook embedding 向量上做连续 FM：数学上可以，但中间状态通常不在码本上，必须规定最后是否重新量化、解码器是否见过这种输入、梯度如何穿过量化。
- 在量化前连续特征上做 FM：可以，但需说明训练/推理与 decoder 的接口。
- 用连续 autoencoder 或弱正则 KL autoencoder：更直接，推荐第一版使用。
- 真正的离散 flow：属于不同建模路线，需要类别转移率或相应离散生成过程，不能直接沿用连续 ODE。

不同模态独立训练的编码器即使输出同样大小，也不保证 latent 尺度和语义一致。不是数学上绝对不能插值，但会增加任意坐标系和尺度差异。可用共享编码空间或经过验证的对齐；另一种合法方案是噪声→OCTA latent 的条件生成，但这应明确区别于 OCT 起点的确定性 FM。

压缩器要先单独验收：把真实 OCTA 编码再解码，评价毛细血管、FAZ 和分层结构。如果这一步已损伤细血管，后续生成网络无法保证恢复患者特异细节。重建结果不是严格数学上界，但它是最直接的容量与信息损失诊断。

小波四子带空间减半、通道变四，系数总数不减少；完整可逆 DWT 不等于学习型有损 VAE 压缩。不能把二者的显存/质量优势混为一谈。

**8. 3D VMamba 值得试，但不应预设成功**

原始 VMamba 的核心为 SS2D 和四条扫描路线；“3D VMamba”需要明确是哪种扩展。维度改成 3 不会自动把二维扫描变成三维联合扫描。[VMamba 原论文](https://arxiv.org/abs/2401.10166)。

必须明确三维序列化、逆序恢复、方向数量、位置/轴信息、时间条件、残差与上采样路径。逐轴正反六方向扫描、全体扁平六种序列化、逐切片 2D 扫描再融合，实际是不同模型。

推荐先用 3D CNN 在高分辨率提取局部细血管，在低分辨率层或 bottleneck 放置双向/多轴 SSM，再用 3D decoder 恢复。这样能提出清楚的假设：局部卷积保细节，较低分辨率 SSM 扩大上下文，而非所有层强行换 Mamba。

固定通道和 kernel 时，卷积随体素数也近似线性增长。Mamba 的线性复杂度主要不能直接用来证明优于 UNet；扫描分支、重排拷贝、状态、kernel 与反向保存都可能增加成本。patch 范围还限制了能看到的全局结构：小 patch 内的全局依赖不等于整个视网膜全局依赖。

当前公开 Mamba 依赖以 Linux/CUDA 为主要路径，本项目本地是 Windows。正式实验建议在 A100 Linux 环境冻结 PyTorch/CUDA/Mamba 版本并做最小 kernel 与梯度验证，不能把安装成功等价于有效使用加速实现。[Mamba 官方安装说明](https://github.com/state-spaces/mamba)。

显存比较必须固定 AE、patch 大小、有效 batch、精度、checkpointing、解码频率与损失；同时报告同等质量下的耗时。把像素 3D UNet 与潜空间 Mamba 比显存，主要测到的是压缩差异。

**9. 推荐实现版本：先建立最小但完整的结构感知 CFM**

建议工作题目：**面向血管与无灌注区域保真的结构感知三维 OCT→OCTA 条件流匹配**。完成实验证据前不把 VMamba、VQ 或“拓扑保持”绑定在标题中。

核心配置：配对三维数据；统一的连续 latent 表示；显式 OCT 条件；可独立评价的投影血管先验；解码端点上的结构监督；3D CNN 主干起步，CNN–SSM 作为受控扩展。

设输入 OCT 为 X，目标 OCTA 为 Y。第一阶段只在训练病例上预训练共享连续编码器 E，配合模态解码头 D_OCT、D_OCTA；完成跨模态 latent 尺度、重建和细血管检查后冻结。共享编码器并不自动保证良好对齐，仍需诊断。若共享空间不稳定，先在固定可逆小波/像素空间验证结构约束，而不是同时引入更多模块。

令：

\[
z_0=E(X),\qquad z_1=E(Y),\qquad t\sim U(0,1),
\]
\[
z_t=(1-t)z_0+t z_1,\qquad u=z_1-z_0.
\]

向量场接收当前状态、时间、源特征和先验：

\[
v_\theta=v_\theta(z_t,t,c_X,h_\phi(X)),\qquad
\mathcal L_{FM}=\mathbb E\|v_\theta-u\|_2^2.
\]

先验分支共享 OCT encoder 特征，输出供条件化的三维特征 h，同时用轻量投影头预测二维血管概率 p。当前版本把 p 定义为与 ILM–OPL 标签对齐的**投影血管先验**；不能直接称为已验证三维血管拓扑概率图。

这比额外一套全分辨率 3D UNet 更合理，也利用了现有二维标签。若一定需要三维概率 P，可以采用二维投影弱监督及训练 OCTA 伪标签约束，但必须明确其深度不可识别性，并补充独立三维验证。

端点估计：

\[
\widehat z_1=z_t+(1-t)v_\theta,\qquad
\widehat Y=D_{OCTA}(\widehat z_1).
\]

训练不需要每个 batch 穿过完整多步 ODE，但这个单步估计并不等于实际自由运行轨迹。验证和最终测试必须从 z0 出发按完整 solver 推理。

若仅在 latent 上使用 MSE 重建：

\[
\widehat z_1-z_1=(1-t)(v_\theta-u),
\]

它就是 FM 误差的时间重加权，不构成新的独立机制。解码后的灰度/血管结构损失才引入额外的图像域监督。[FM 基础定义](https://arxiv.org/abs/2210.02747)。

推荐总目标：

\[
\mathcal L=\mathcal L_{FM}
+\lambda_{img}\mathcal L_{img}
+\lambda_{proj}\mathcal L_{proj}
+\lambda_{prior}\mathcal L_{prior}
+\lambda_{struct}\mathcal L_{struct}.
\]

各项必须有明确计算对象：

| 项 | 明确定义 | 作用 |
|---|---|---|
| L_img | 预测 OCTA 与真实 OCTA 的 L1/Charbonnier，必要时加入适度 SSIM | 灰度与结构重建；MSE 可保留作对照 |
| L_proj | 对相同层边界和相同操作算出的 P_k(Ŷ)、P_k(Y) 做 L1 | 分层空间一致性；只称结构，不称三维拓扑保证 |
| L_prior | p(X) 与训练病例二维血管标注做 BCE + Dice | 让先验有可解释监督，阻止仅凭命名宣称其是血管 |
| L_struct | 生成投影经固定 S_loss 得到 q，与标注做 Dice + soft-clDice，并显式处罚可信无血管区假阳性 | 同时约束漏检与虚构，避免“越连越好” |

S_loss 是只使用当前训练病例真实投影训练的辅助分割器，冻结权重但保留对其输入的梯度。它是实现结构损失的一种稳妥工程方案，也引入额外预训练，应诚实披露。它与 TransPro 等已有血管指导相关，因此**本身不是足够的新颖性**。

若坚持不预训练 S_loss，可先用验证集确定的可微软阈值或固定 vesselness 作为代理，但必须承认它不是准确的血管分割；联合训练一个自由的分割头与生成器互相满足损失，存在共同作弊或走捷径风险。

L_struct 可写为：

\[
q=S_{loss}(P_{inner}(\widehat Y)),
\]
\[
\mathcal L_{struct}=1-\operatorname{Dice}(q,M)
+\alpha[1-\operatorname{softclDice}(q,M)]
+\beta\frac{\sum q\,M_{absence}}{\sum M_{absence}+\epsilon}.
\]

M 是定义明确的血管标注，M_absence 仅取训练病例有可信标签的无血管区域，如相应内层 FAZ；不能把所有弱信号都视为阴性，也不能把 FAZ 掩膜沿所有深度任意复制。病理无灌注 ROI 需额外专家标注后才作对应强监督。

clDice 是既有的中心线相关损失，不是新增贡献。二值结构上特定条件下的理论结论，也不等同于生成灰度体用 soft-clDice 就获得严格拓扑保证。[clDice 原论文](https://arxiv.org/abs/2003.07311)。

训练时初始较低的结构权重、稳定后逐步升高可作工程选择；必须记录日程并在全部相关实验一致使用。权重从验证集选择，关注梯度规模和图像质量–假阳性权衡，不预先填一组“最优值”。

**10. 如果要保留“流过程结构引导”，需要更强的实验**

最基础的 p/h 条件拼接加终点损失，只支持“结构条件化 FM”。它不支持“整个 ODE 过程保拓扑”。

可以研究一个更具体的扩展：在若干时间点对**各时刻预测的终点 OCTA**施加血管存在与缺失一致性，并比较标准终点监督、时间调制条件、短 ODE rollout 监督。不能要求原始中间 OCT/OCTA 混合图都具有最终 OCTA 的骨架；它们本来不属于同一物理模态。

若使用自由运行短 rollout，训练轨迹更接近推理，但增加内存和计算；应作为明确可消融的选择，不能一开始全加。若使用显式能量梯度修正向量场，需要说明原 ODE 被改变，评估 solver 稳定性、额外网络计算次数和标注依赖。

2026 年已有 *Topological Flow Matching* 研究将结构域信息纳入参考过程。它的图/复形域拓扑与 OCTA 图像内血管形态拓扑不同，但“首次拓扑感知 FM”这种宽泛创新表述已不合适。[相关工作](https://arxiv.org/abs/2606.15897)。

最有说服力的升级不是继续加名称，而是证明：结构信号在生成过程中以患者相关、可靠且不过度连通的方式起作用，并在独立标注上减少假血管。

**11. 三维拓扑证据的两条可行路线**

路线 A：使用现有数据，明确限定证据范围。

- 生成输出是真正三维体，做三维灰度评价、B-scan 和层定位评价。
- 血管监督与主结构评价采用二维人工/模型辅助投影标签。
- 三维阈值/分割伪标签上的 clDice、连通分量等仅作为探索性结果。
- 论文写“改善体生成的血管结构保真与投影连通性”，不写“证实完整三维微血管拓扑正确”。

路线 B：保留三维拓扑作为主贡献，则增加独立三维证据。

- 在事先固定的病例/区域上制作小规模三维血管中心线或体素 ROI 标注。
- 纳入正常、稀疏毛细血管、病理无灌注、疑似假连接等困难区域，预先制定采样规则。
- 至少双阅片者或复核流程，记录分歧和观察者一致性。
- 明确排除 patch/FOV 边界上的天然截断点，按物理距离进行骨架与分支匹配。
- 仍需说明真值来自 OCTA 观测，不能把算法标签称为组织学真实血管。

可以先做小规模可标注性试验决定投入，而不是承诺全 500 例血管三维精标。若没有合作者或预算，选择路线 A，并相应降低结论范围。

**12. 数据划分与泄漏控制**

FlowOCT 和 MuTri 报告的生成划分数量为：3 mm 140/10/50；6 mm 180/20/100。数据集新版分割协议为 6 mm 240/10/50，和前者不同。[MuTri 实验设置](https://arxiv.org/html/2504.01428v1)，[OCTA-500 第 5.1 节](https://arxiv.org/pdf/2012.07261)。

建议把常见编号协议作为待锁定 manifest，而不是只写“官方划分”：

| 子集 | 训练 | 验证 | 测试 |
|---|---|---|---|
| 3 mm 生成协议 | 10301–10440 | 10441–10450 | 10451–10500 |
| 6 mm 生成协议 | 10001–10180 | 10181–10200 | 10201–10300 |
| 6 mm 新版分割协议（仅列差异） | 10001–10240 | 10241–10250 | 10251–10300 |

正式声称“完全与 FlowOCT/MuTri 一致”前仍需核对其具体 ID 清单；相同数量不保证相同病例。不能混用不同版本已发表数值。

尤其危险：按新版分割协议训练的辅助分割器，可能见过生成协议的 10201–10240 共 40 个测试病例。即便生成器没有直接训练这些病例，先验、结构损失或评估器也已引入测试信息。所有 AE、码本、分割器、层定位器、伪标签模型、归一化统计都必须审查训练来源。

禁止随机按切片拆分。患者/眼/扫描的关联需明确；训练增强、切块与 latent 缓存均在划分后产生。验证用于选权重与停止，测试仅锁定后使用。已有第三方 checkpoint 若训练清单不明，不能直接作为主评估器。

3 mm 与 6 mm 分别训练分别测试说明两个子集上的表现；3→6 或 6→3 零微调才是跨子集迁移，还同时受视场与疾病分布影响。另一台设备/中心、相同目标的独立数据才是更强外部泛化。不能把只有二维 OCTA 标签、没有配对 OCT 体的数据集用来验证三维跨模态生成。

**13. 评价指标的完整版本**

原表里的 Dice/VOE 衡量重叠，不直接衡量拓扑。若 VOE=1-IoU，它与 Dice 是单调变换，信息高度重复。“连通性准确率”与“断裂点计数”没有唯一标准，必须给公式、阈值、骨架化和边界规则。

| 层面 | 建议指标 | 注意 |
|---|---|---|
| 灰度 | MAE、PSNR、SSIM | 固定 data_range；说明三维 SSIM 还是逐切片平均 |
| 稀疏前景 | 前景 MAE/PSNR、背景假阳性 | 定义 mask；参考真值的评估 ROI 可以用，但不能进入推理 |
| 分层 | FULL、ILM–OPL、OPL–BM 一致投影比较 | 用相同操作；不把 full mean 偷换成 MIP |
| 血管分割 | Dice、precision、recall | 区分全血管、大血管、定义明确的毛细血管 |
| 中心线 | clDice、中心线 recall/precision | 标准化 skeleton、阈值及物理匹配容差 |
| 错误连接 | 分支匹配、错误桥接、局部连通性 | 需要图匹配/独立 ROI；不能只数端点 |
| 无灌注保真 | FAZ 面积误差、FAZ 内 FP、独立缺血 ROI FP | 面积以 mm²；病理缺血需相应标注 |
| 三维结构 | 经独立标注的 3D ROI clDice/断裂；探索性 Betti error | 没有独立血管体标注就限制结论 |
| 下游用途 | 冻结真实 OCTA 分割器的 real-vs-synthetic 差距 | 和 S_loss 独立，病例严格不泄漏 |
| 效率 | 峰值显存、训练 step 耗时、全体推理耗时、NFE、总训练成本 | 包含编码/解码、先验、拼接与全部必要模块 |

主评估器 S_eval 使用同一训练集合的真实 OCTA 训练，验证调参后冻结；建议使用不同于 S_loss 的结构/训练过程，并加一个不同分割器或规则法做敏感性分析。真实 OCTA 通过相同 evaluator 的结果是测量参考，不是不可超越的数学上限。

报告：Dice(S_eval(P(Y)),M)、Dice(S_eval(P(Ŷ)),M) 以及二者差距。辅以人工盲评小 ROI，避免把某个分割器的偏好当作临床真理。

投影正确无法证明深度位置正确，3D MIP 尤其可能掩盖上下层粘连。定性图至少包含 B-scan、解剖分层投影、局部三维 ROI 和失败病例，保持阈值/窗宽一致，禁止逐方法调到最好看。

不能只用端点数量：断裂可能增加端点，去掉真实小分支也会减少端点，错误桥接同样可能减少端点。Betti 数相同的血管图也可能完全位于错误位置，须结合几何匹配。

以病例为统计单位，建议关键配置 3 个随机种子，报告每病例配对差异及 bootstrap 95% CI，必要时配对检验及多重比较控制。不同 seed 与患者不是独立的 n 倍样本。不要将几万张切片当成几万例受试者。

**14. 消融需要拆开因果因素**

原 A1–A4 可以研究“主干 × 拓扑模块整体”的 2×2 交互；它不能分离先验分支和损失，而且 A1 还被错误定义成原版 3D FlowOCT。

推荐核心矩阵如下。所有行固定同一连续 AE、数据、训练预算、基本 L_img/L_proj 与 solver：

| 编号 | 主干 | 有监督先验并反馈生成器 | 生成输出结构损失 | 解释 |
|---|---|---|---|---|
| C0 | 3D CNN | 无 | 无 | 受控基础模型 |
| C1 | CNN–SSM | 无 | 无 | 主干效应 |
| C2 | 3D CNN | 有 | 无 | 先验条件效应 |
| C3 | 3D CNN | 无 | 有 | 输出结构损失效应 |
| C4 | 3D CNN | 有 | 有 | 不依赖 Mamba 的完整结构方案 |
| C5 | CNN–SSM | 有 | 有 | 候选完整模型 |
| C6（补充） | CNN–SSM | 有 | 无 | SSM 下的先验效应 |
| C7（补充） | CNN–SSM | 无 | 有 | 补齐三因素矩阵 |

若贡献依赖三因素各自效果和交互，完整 2×2×2 八组优于只做六组。算力有限先 C0–C5，出现交互或需强解耦时补 C6/C7，不用“硬性四组”替代证据设计。

优先补充的对照：

- 同等参数的辅助分支、同样血管监督但不将先验反馈生成器：区分额外容量/多任务监督与条件先验。
- 将先验跨患者打乱/置零：验证患者特异性；推理干预只作为诊断，训练匹配对照更强。
- 只用 Dice 与 Dice+clDice，再加无灌注阴性项：验证细血管与假连接权衡。
- 真实 OCTA→AE→重建的结构损失：量化压缩代价。
- 同样 AE 下连续与 VQ；若 VQ 没有必要就不再扩展。
- 同 NFE 的 solver 比较及同质量成本比较；不要用 3 步 FM 对比未调节预算的 1000 步 diffusion 来制造效率优势。

只有额外标注监督的模型优于无额外监督基线，不足以说明架构更好。报告监督资源，给关键基线同样损失或辅助监督的增强版本。

**15. 应比较什么方法**

优先级：修复后的公开 FlowOCT、自建匹配预算的 3D CFM、3D 直接回归 CNN、3D Pix2Pix、TransPro、MuTri、XOCT，以及至少一个调好条件和预算的 3D diffusion/latent diffusion 或图像桥基线。

TransPro 已使用血管分割指导和投影上下文；XOCT 已研究跨维度多尺度结构；MuTri 已有多视图和血管结构对齐，不能略过这些最相关工作，只赢通用 GAN 后称 SOTA。[TransPro](https://arxiv.org/abs/2303.06807)，[XOCT](https://papers.miccai.org/miccai-2025/1024-Paper4977.html)，[MuTri](https://openaccess.thecvf.com/content/CVPR2025/html/Chen_MuTri_Multi-view_Tri-alignment_for_OCT_to_OCTA_3D_Image_Translation_CVPR_2025_paper.html)。

CycleGAN 是非配对方法，可作历史参考，不是配对生成最强或必需的主基线。你自己的三维适配需明示适配内容，不能把某个自实现版本自动冠以该类别 SOTA。

统一数据不意味着所有方法同一套默认参数；应给合理、记录完整的调参预算。记录预训练数据、输入监督、模型选择、NFE 和总计算预算。公开报告与统一重跑分开，MAE/PSNR 的数值范围、SSIM 实现和投影运算确认一致后才能合表。

**16. 实现中的实质难点**

| 项目 | 必需处理 |
|---|---|
| 模型接口 | 当前代码把 optimizer、loss、更新写在 forward；研究版分开数据、AE、vector field、loss、solver、评估 |
| 3D 前向 | 原代码先展平成切片；必须保持 5D 张量，不能只将 spatial_dims 改 3 |
| 时间条件 | 3D FM 每体/patch 一个 t，正确广播到 5D；time embedding 注入各层 |
| 投影 | 沿解剖深度、每患者独立，不能沿混合 batch/slice 的维度求 max |
| 可微性 | 训练不用硬阈值+skimage skeletonize；hard 骨架只作离线指标 |
| 冻结 decoder | `requires_grad=False` 冻结参数，但对预测 latent 解码不能包 `no_grad()`，否则结构损失传不回生成器 |
| 同理分割器 | S_loss 固定参数而不切断对图像的梯度；S_eval 才完全 no_grad |
| 缓存 | 冻结编码器可缓存目标 latent；几何增强、裁剪与对应标签必须一致 |
| AMP | 3D soft skeleton 和 SSM kernel 分别验证数值范围，必要部分 FP32，不能盲用 FP16 |
| 边界拼接 | overlapping inference 和一致的 crop/pad 记录，评价 patch seam；不能让拼接制造血管断裂 |
| 模型状态 | 明确 train/eval、固定 seed、保存 optimizer/scheduler/AMP/RNG，能够准确恢复训练 |
| 数据格式 | 压缩 npz 对频繁随机 patch 读取可能昂贵；按实际 I/O 选择可内存映射或分块存储 |

当前 `working` 已修复投影 ROI 丢失通道维的索引问题，但仍有 batch>1 投影混患者、crop min-max 零分母、三轴强制 resize 等研究协议问题。必须分别记录基础修复与方法改动，不能拿修复后的新模型去对比已知错误的旧基线以声称创新。

建议新增独立 research 实现目录，保留 upstream 和 working 作为可追溯基线。可分为 manifest/几何预处理、AE、3D vector field、prior、projection/loss、solver、evaluate 七个模块。当前任务只完成审查，没有替你创建未经验证的新模型。

**17. A100 80GB 与训练起点**

一张 A100 80GB 足以作为 patch/潜空间方案的合理开发平台，但不是全分辨率训练保证。仅 400×400×640 的一层、32 通道 FP16 特征就约 6.55 GB（十进制），尚不含其它层、梯度、优化器、SSM 和 decoder。

第一轮可尝试的设置，仅为起点：

- 3 mm 先跑；使用覆盖有效视网膜深度、横向约 128×128 的 patch，Z 范围由训练集覆盖率决定，不预设任意固定裁剪。
- 连续 AE 先测试温和下采样，关注横向毛细血管；示例 `(Z,H,W)` 下采样倍率 `(4,2,2)`，实际以重建检查调整。
- batch=1 起步，必要时梯度累积；GroupNorm/LayerNorm；在支持时 BF16，关键损失局部 FP32。
- AdamW、学习率约 1e-4 作为研究模型起点，短 warmup 后 cosine；原版基线保持其合理原协议。
- 先运行 20–50 个预热/测量 step，再估算完整实验时长。不得用只算 FM backbone 的峰值替代全部损失实际峰值。
- 缓存冻结的 latent；结构损失可以低频计算或局部解码，但要明确采样策略，验证是否偏向低成本病例/区域。
- 验证 NFE 可预先给定小网格，例如 1、3、5、10，Heun 与 Euler 按实际函数调用数计费；测试不逐病例选择步数。
- 固定训练 update 数与有效样本暴露量，保留 early stopping 和计算预算。无测量前不承诺“多少天训完”。

AE 预训练、辅助模型、失败实验、全部消融和所有 seed 的成本都算总成本。单个配置能跑通与整篇论文资源足够是两个问题。

**18. 分阶段决定是否继续投入**

| 阶段 | 工作 | 通过标准 | 未通过怎么办 |
|---|---|---|---|
| P0 数据与协议 | 恢复 10294；核对轴/标签/投影/划分，锁定 manifest | 数据可读且配对；无标签/病例泄漏 | 先修数据与协议，暂停方法扩展 |
| P1 测量工具 | 真实投影分割器、统一图像/结构指标、少量专家 ROI | 测量真实 OCTA 有效，指标含义清楚 | 修测量工具，不能直接宣布生成失败 |
| P2 可靠基线 | FlowOCT public + fix，直接 3D 回归，3D CFM | 单体过拟合、完整推理与验证一致，成本可测 | 修实现和优化，不急着加 Mamba |
| P3 压缩可用性 | OCTA 的 AE 重建与微血管评价 | 保留主要结构，成本下降有意义 | 减少压缩或改小波/patch 路线 |
| P4 结构假设 | 固定 CNN，先分离先验与损失 | 连通性改善且 FP/缺血填平不恶化；跨 seed 稳定 | 弱化/删除先验，重新设计结构目标 |
| P5 主干价值 | 匹配资源 CNN–SSM 比较 | 同质量下效率或结构明显获益 | 保留 CNN，放弃无贡献的 Mamba |
| P6 论文证据 | 最相关基线、完整消融、病变/跨子集/独立 ROI | 主假设成立且局限清楚 | 收缩主张，不编造全面最优结论 |

可以预先约定一个非劣容忍区间和最小结构改善幅度，但必须结合验证噪声、患者相关误差和临床意见确定，不应无依据制定“提升 5% 就算成功”。若只有 PSNR 上升而毛细血管精度或病理区域变差，应认为核心科学假设未得到支持。

**19. i2SB 不建议作为当前升级方向**

I²SB 的正式名称为 Image-to-Image Schrödinger Bridge，“I²”不是“插值”的简称。它连接两个分布，并不自动给你一个可靠的 OCT↔OCTA 双向模型，也不自动提供患者正确性自检。[I²SB 原论文](https://arxiv.org/abs/2302.05872)。

满足条件的确定性 ODE 可数值反向积分；带固定 OCT 条件的反解并不等于从 OCTA 单独生成 OCT。训练独立反向模型也不要求必须使用 i2SB。循环一致性仍可能允许相互一致但错误的映射，所以不能当作真实性证明。

当前真正缺少的是可靠血管/病理证据与干净比较。换桥框架会同时改变训练目标、路径、噪声和 solver，增加归因困难。“一定更慢更难收敛”也需实测，不能作为先验事实。

**20. 贡献与投稿表述的修订**

原贡献 1 与 3 属于同一结构约束机制的不同部分，不能靠拆段变成两个独立创新；贡献 2 是需证明价值的架构选择；贡献 4 是论文必须给出的实验支撑，不天然是新的科学贡献。

建议按实际结果写成三个层次：

1. 提出针对血管存在与缺失保真的结构条件化三维生成方法，明确先验来源、约束位置和病理保护机制。
2. 在现有投影标签与有限三维信息下设计可审计的监督和验证流程；如果增加独立三维 ROI 标注，这可以构成实质数据/评价贡献。
3. 通过分离监督、主干、压缩和推理成本的实验，说明何种条件下改善毛细血管而不增加假血管；只有测出优势后才强调 SSM 效率。

不能在实验前写“取得所有指标最优”“大幅提升”“临床可靠”。更好的研究目标允许结果显示取舍，例如微血管结构改善但灰度 PSNR 略降，并解释为何可信。

TMI/JBHI 都与主题相关，但不能把模块数量当作接收条件。TMI 官方明确关注方法创新和金标准/评价解释；成熟模块的直接拼接、单数据集常规消融，通常不足以支撑强创新主张。独立病理验证和可信评价会显著提高工作价值，但也不构成录用保证。[TMI 范围](https://ieeetmi.org/scope/)，[接收关键标准](https://ieeetmi.org/key-criteria-for-publication/)。

“SCI 一区、CCF B、顶刊”属于不同评价体系，需按年份、类别和学校认可口径核验，不能作为一个统一技术定位；也不存在通用的“固定四组消融就是一区硬性要求”。本次不对未核实的最新分区作保证。

**最终建议**

现在应开展一次小规模、严格控制变量的可行性研究，而不是立刻写出 Full 模型并启动全部对照。第一优先级是数据损坏、轴/投影约定、监督与测试泄漏；第二优先级是证明结构目标不会填平真实缺血；第三优先级才是连续潜空间与 CNN–SSM 的成本收益。

如果坚持“完整真实三维拓扑”作为主贡献，当前数据证据不足，需要额外三维标注/专家验证。如果接受“真正三维生成 + 投影结构监督 + 三维灰度/层定位验证”的范围，可以基于现有数据实现，且这是一条诚实、可推进的起点。最终是否保留 Mamba、VQ、拓扑分支，由消融决定。

原始核查记录位于 `artifacts/proposal_review_20261004/dataset_audit.json`、`metadata_audit.json` 和 `geometry_probe.json`。这些记录只证明本次检查范围内的数据事实，不代表模型有效或临床验证完成。
