# 逐步学习课程：每节都有代码、练习和验收

可以每节安排1～2次学习，每次60～90分钟。时间仅为建议，按掌握程度前进。不要因为执行了命令就自动勾选完成。

## 第1课：张量与广播

读《数学与张量基础》1～5节。运行 `learning/01_tensor_and_flow.py`。

先在纸上写下输入 `(B,C,D,H,W)` 每维含义。手工选4张slice，解释permute和reshape前后每个维度。将B设2；将t设0/1/0.5；核对x_t端点。

验收：不运行代码也能预测输出shape；能说明t为何不能直接用长度D的向量与任意五维体相乘。

## 第2课：训练到底训练什么

仍用01脚本，观察scalar parameter的梯度和optimizer更新；把`optimizer.step()`暂时注释，看loss backward后参数是否改变；把zero_grad暂时去掉连续训练两步，看梯度累计。

验收：能区分输入值、目标值、可训练参数、梯度；说出backward和step各自的职责。练习只改教学副本，不改原仓库。

自测答案：backward计算/累加梯度；step按optimizer改变参数；zero_grad清除上一轮梯度；模型forward通常只计算输出，但FlowOCT的forward将全部优化步骤写在内部。

## 第3课：手推Flow Matching

用a=0.2、y=0.8，分别算t=0.25/0.5/0.75时的状态和目标速度。换成2×2矩阵，用每个像素独立计算验证张量意义。

自己写出 `x_t=(1-t)*a+t*y`、`u=y-a`、MSE；不要抄完就结束，解释为何推理时不能直接算y-a。再说明噪声起点的条件FM与FlowOCT的区别。

验收：能在不看笔记的情况下写出训练三式和生成ODE，说明每个变量从哪里来。

## 第4课：Haar小波与梯度

运行 `learning/02_wavelet_and_gradient.py`。看DWT/IDWT两个文件，先只读2D类和Function。

画一个2×2像素块的低通/高通组合；解释LL与高频带。保留四带重建，然后将HH清零，观察误差。注意wavelet系数可以有负值，不应像原图一样一律clip到[0,1]。

验收：能解释1→4通道、宽高减半、四带元素总数、为什么固定变换仍可传梯度。能复述`y=Lx`时梯度需要乘Lᵀ。

## 第5课：从Dataset开始追一个患者

读dataset所有函数。先查看人工`.npz`，打印keys、shape、dtype、min/max。然后把真实raw数据放入指定目录，确认首个患者轴与配对关系。

运行pack_pair（仅适用支持格式）与check_dataset。读取同名JSON，画三个索引切面。不要在没确认轴之前给它们强行起解剖名字。

验收：能解释resize、crop、flip、min-max的实际顺序；能说明随机flip必须两模态一致；知道一个体非常量仍可能某个crop全零。

## 第6课：模型训练forward逐块走

按《全部代码精读》5.5节读原forward。给每个中间变量在笔记中标shape：real_A、indices、oct_flat、t、x_t_dwt、pred_dx、pred_octa_flat、embedding、projection。

在**临时学习副本**中每步加少量print或断点，避免每个batch打印巨大张量。记录输出shape与一两个统计量即可。

验收：能画出训练的数据流，说明哪一步有GT、哪一步变成2D、哪些网络参数被Adam优化。

## 第7课：四个损失和投影bug

读auto_crop、cropped losses、contrast、projection。运行 `tools/probe_projection_roi.py`，对照 `patches/projection-roi.diff`。

你需要自己说明为什么 `(1,32,32)[4:28,10:22]` 第一段裁的是C维而不是H维；正确写法如何保留channel。

contrast部分用M=2在纸上画4×4相似度矩阵，圈出self/positive/negative；再考虑M=1为什么loss为0。

验收：能说明裁bbox不是血管mask；能解释detach并未切断ROI内预测强度梯度；能发现B>1时projection跨患者混合。

## 第8课：第一次完整运行

运行 `tools/run_upstream_smoke.py --name my_first_smoke`（新name）。从train.log查看两次参数更新、validation和保存标签；从test.log确认加载同标签。

用visualize_results和evaluate_results保存图/CSV。看预测尚未接近目标的事实，练习区分“软件链路正确”和“训练质量达标”。

验收：知道测试默认latest为什么不工作；能手工找到正确权重；说出该运行未证明真实医学有效性。

## 第9课：生成与NFE

只读euler_step/generate/_generate_3d/validation/test。自己写0→1的三步循环，确认没有GT。手动用同一权重测试1/3/5步，不要重新训练掩盖solver区别。

计时先预热、CUDA synchronize，在统一chunk/尺寸下重复；记录每切片NFE与整个体chunk网络调用次数。切勿把未同步的启动耗时当GPU实际完成时间。

验收：能解释training path与实际sampling trajectory为何可能不同；知道逐步clamp会改变纯ODE解的性质。

## 第10课：走进MONAI U-Net

读本机网络源代码的DiffusionModelUNet构造与forward，再读time embedding、residual block、SpatialAttentionBlock相关段。对照 `artifacts/monai_network.json`。

画下采样/skip/上采样图。说明t先变32维再变128维、为何with_conditioning=False仍有self-attention、为什么没有源OCT cross-attention。

验收：能区分U-Net主结构、self-attention、cross-attention、DiT；不再根据类名判定训练机制。

## 第11课：你亲手写一个真正3D速度模型

运行：

```powershell
python learning/03_minimal_3d_fm.py --steps 60 --output artifacts/course_3d
python learning/03_minimal_3d_fm.py --steps 60 --explicit-condition --output artifacts/course_3d_cond
```

先读TimeBlock，再读Tiny3DUNet：Conv3d提局部体特征；时间Linear广播到空间；下采样看更大邻域；上采样与skip结合。最后读main：随机t→velocity MSE→update→三步推理。

把patch从16³改成合理偶数尺寸，自己预测middle尺度；把3D t广播误改成四维，观察并解释错误，然后恢复。比较有/无condition，在同budget下看结果，理解“合理设计也可能暂时没改善”。

验收：能从空文件写一份最小3D FM，能指出该示例只过拟合一个人工体、不说明泛化。

## 第12课：第一份正式实验计划

填写实验模板，先只选择2D vs 2.5D或2D vs小3D的问题。写明患者划分、真实轴、预处理、主指标、有效训练预算、模型选择、至少一项容量对照。

列出三个能推翻假设的结果，再列出排查步骤。开始训练前把该计划保存；实验结束后只根据证据写结论。

验收：另一个人拿你的配置、代码版本、数据清单和命令，能重跑同一协议；你能解释每个模块存在的原因。

## 每次读代码用这六个问题

1. 输入是什么、哪个维度是什么？
2. 输出是什么、变化在哪里？
3. 是否有可训练参数？
4. GT在这里用于网络输入、监督、还是仅评分？
5. 哪条通路可微、哪里detach/CPU转换？
6. 失效条件是什么、怎样用最小样例验证？

最后一节结束后，你不需要背下所有函数。你需要能够沿调用链找到问题、写最小证据、控制实验变量，并诚实报告仍未验证的部分。
