# 从公式到张量：看懂 FlowOCT 的最小基础

## 1. 图像状态与参数是两个不同的东西

一张灰度图 `(1,H,W)` 是由 H×W 个强度组成的张量，也可看成高维空间的一个点。FM 中的“移动”是这些强度改变，不是血管在屏幕上移动。

模型参数 θ 是卷积核、线性层权重等。训练改变 θ；生成改变图像状态 x。两者都用“更新”这个词，所以特别容易混淆。

| 操作 | 被改变的对象 | 是否需要真实 OCTA | 是否调用 backward |
|---|---|---|---|
| 一个训练优化步 | 网络参数 θ | 需要，作为监督目标 | 是 |
| Euler 生成一步 | 当前图像状态 x | 不需要 | 否 |
| 验证指标计算 | 统计量 | 需要，用于评分 | 否 |

## 2. 三个公式从哪里来

定义配对样本 `a=OCT`、`y=OCTA`，代码中源/目标都已在相同网格上处理并归一化。

先连接两端：

\[
x_t=(1-t)a+ty=a+t(y-a),\qquad t\in[0,1].
\]

当 t=0 是 a，t=1 是 y。对 t 求导时，这对样本 a、y 固定：

\[
u_t=\frac{dx_t}{dt}=y-a.
\]

训练时知道 a、y，所以可以直接算这个目标；推理时不知道 y，只能让模型预测：

\[
\hat u=v_\theta(x_t,t).
\]

最基本的损失是平均平方误差：

\[
L_v=\frac1{MHW}\sum_{i,h,w}(\hat u_{i,h,w}-u_{i,h,w})^2.
\]

这里 M 是展开后的切片数量。MSE 是每个元素的误差平方再平均，不是随意给公式一个名称。平方让正负误差不能抵消，也让大误差贡献更大。

一个标量例子：a=0.2、y=0.8、t=0.25，则 x_t=0.35、u=0.6。若网络预测 0.5，速度误差平方为 0.01。图像中每个像素都同时做这种运算。

## 3. 一次训练抽一个 t 为什么可以

要优化的是对数据和时间的期望：

\[
\mathbb E_{(a,y),t\sim U(0,1)}\|v_\theta(x_t,t)-(y-a)\|^2.
\]

每个优化步用有限 batch 和随机时间近似该期望。多次更新会覆盖大量样本和时间。相同参数共享在所有时间上，时间嵌入告诉网络“现在在什么阶段”。不是一个 t 对应一套独立权重。

当前代码对每张选中的 slice 分别抽 t，所以一个体 batch 内可以有很多不同时间。它没有为了一个训练样本把网络从 0 跑到 1。

网络一次预测速度，不代表一步准确得到目标。训练学的是局部速度预测；生成仍可按多个时间步使用它。若做单步，通常是 Euler 步长=1，近似误差需要独立验证。

## 4. MSE 最优预测为什么是条件均值

如果某个输入状态对应多个可能目标速度，对预测值 q 有：

\[
\mathbb E[\|q-u\|^2\mid x_t,t]
=\|q-\mathbb E[u\mid x_t,t]\|^2+\operatorname{Var}(u\mid x_t,t).
\]

第二项不取决于 q，因此第一项最小时 q 为条件均值。这说明网络总结的是速度规律，不会背住每条配对直线。

这不等于“生成端点就是所有 OCTA 的像素平均”。端点由学到的速度场积分得到，两者不能直接画等号。还要注意：当前 FlowOCT 使用裁剪损失和额外损失，上述最优条件均值结论只直接对应基本全域平方损失。

一般 FM 的概率流理论依赖适当的分布、正则性和精确速度等条件。真实有限数据、有限网络和三步积分不自动保证保持所有患者血管或零幻觉。[FM 原始论文](https://arxiv.org/abs/2210.02747)将 FM 表述为固定条件概率路径上的向量场回归训练。

## 5. 张量形状逐个推

默认公开代码设置 `B=1,C=1,D=H=W=256`。D 在代码里是第三个数组轴，不一定已经证明是解剖学的 retinal depth。

| 阶段 | 符号/变量 | 默认形状 | 教学形状 |
|---|---|---|---|
| 输入体 | `real_A, real_B` | `(1,1,256,256,256)` | `(1,1,32,32,32)` |
| 抽取 N=D//4 张 | `oct_slices` | `(1,1,64,256,256)` | `(1,1,8,32,32)` |
| 调换次序 | `permute(0,2,1,3,4)` | `(1,64,1,256,256)` | `(1,8,1,32,32)` |
| 展开 | `oct_flat` | `(64,1,256,256)` | `(8,1,32,32)` |
| 随机时间 | `t` | `(64,)` | `(8,)` |
| 广播时间 | `t_img` | `(64,1,1,1)` | `(8,1,1,1)` |
| 中间状态 | `x_t` | `(64,1,256,256)` | `(8,1,32,32)` |
| 四频带拼接 | `x_t_dwt` | `(64,4,128,128)` | `(8,4,16,16)` |
| 频带速度 | `pred_dx_dwt` | 同上一行 | 同上一行 |
| 空间速度 | `pred_dx` | `(64,1,256,256)` | `(8,1,32,32)` |

`permute` 改轴次序，`reshape` 将 B 和 N 合并。直接 `reshape(B*N,C,H,W)` 而跳过 `permute`，当 C>1 时可能混乱语义，不能靠元素数相同判断正确。

`t_img` 后三维为 1，使每张 slice 的一个时间值广播到全部空间位置。三维 FM 对一个 patch 的时间应是 `(B,)`，广播后为 `(B,1,1,1,1)`。多 patch batch 时每个 patch可取不同 t；计算跨深度辅助目标时一般应保持同一个体内的一致时间语义。

## 6. Wavelet 为什么 1 通道变 4 通道

Haar 小波先对行/列做低通和高通，再下采样。二维分解形成 LL、LH、HL、HH 四个频带。输入 H×W，单频带约 H/2×W/2，合起来的元素数仍为 H×W。

“宽高减半”不能解释成“无损地减少总信息量”。完整保留四个频带的 Haar 变换在适当尺寸下可逆；网络的第一层和中间特征成本可能改变，但四个输入通道并不是压缩掉了 3/4 信息。

在当前代码：

\[
\hat u=W^{-1}\big(g_\theta(W(x_t),t)\big).
\]

网络预测 wavelet 系数形式的速度，经 IDWT 返回图像速度；实际 `vloss` 在图像空间的裁剪 ROI 计算。没有单独四套频带网络，也没有四个显式独立频带 loss。

线性变换满足 `W((1-t)a+ty)=(1-t)W(a)+tW(y)`，所以先插值再 DWT 与先 DWT 再插值在线性代数上等价。但裁剪、mask、clamp 和非线性网络加入之后，整体训练目标不能简单宣称全都等价。

三维可分离 DWT 有 8 个频带，而不是 4 个。若保留三维 wavelet，你不仅要改 `spatial_dims`，还要改通道、变换、训练张量、projection、head 和推理路径。

## 7. 由当前位置估计终点

从线性路径得 `y=x_t+(1-t)u`。用预测速度替代：

\[
\hat y_t=x_t+(1-t)\hat u.
\]

如果预测速度精确，这一式在任何 t 都能恢复 y。真实网络不精确，所以这只是终点估计，用来算 L1、对比和投影监督，不是一次完整 ODE 推理。

未 clamp 时：

\[
\hat y_t-y=(1-t)(\hat u-u).
\]

因此 t 接近 1 时，重建损失对速度误差的梯度会缩小；它与直接速度 MSE 的作用不是完全相同。`clamp(0,1)` 还会让范围外位置的梯度受限。这些都是你看损失曲线时需要考虑的机制。

## 8. 四个损失怎样理解

公开代码总损失：

\[
L=10L_v+0.5L_{L1}+0.005L_{contrast}+0.1L_{proj}.
\]

- `L_v`：裁剪后的速度 MSE，监督运动方向和大小。
- `L1loss`：裁剪后的端点重建，鼓励强度接近。
- `contrastloss`：假/真同一选中切片的 embedding 为正对，其它选中切片为负对，使用温度 0.1。
- `proj_loss`：在选中切片（并合并 batch）上取逐像素最大值，再算裁剪 L1。

系数大小不能代表重要性。例如 Lcontrast≈3，乘 0.005≈0.015；Lv≈0.01，乘 10≈0.1。还要看对共享网络的梯度大小和方向，不只是看数值。

对比损失的单个 anchor 可写为：

\[
-\log\frac{\exp(s_+/\tau)}{\exp(s_+/\tau)+\sum_j\exp(s_j^-/\tau)}.
\]

`s` 是归一化向量点积。越相似越接近 1。正对要相似、负对要区分。如果只有一张有效切片，根本没有负对，损失为零，没有对比学习效果。相邻切片可能本来就很相似，作负对是否合理也是可研究的问题。

## 9. 从 ODE 到三步 Euler

训练好后解：

\[
\frac{dx}{dt}=\hat u_\theta(x,t),\quad x(0)=a.
\]

固定三步意味着 t=0、1/3、2/3 处各调用一次网络：

\[
x_{k+1}=\operatorname{clip}_{[0,1]}\left(x_k+\frac13\hat u_\theta(x_k,k/3)\right).
\]

每次更新再重新预测速度，不是先算一个速度复制三次。公开代码每步都 clip，因此更准确是“带逐步投影的 Euler 更新”；它与不加约束的纯 ODE 数值解不完全相同。

| 求解器 | 一步做什么 | 固定 K 步的大致 NFE |
|---|---|---|
| Euler | 起点速度一次 | K |
| Heun | 起点与预测终点速度，再平均 | 2K |
| RK4 | 四次速度评估形成加权和 | 4K |
| 自适应 RK | 根据误差调整步长，可能拒绝某步 | 可变，必须记录实际调用 |

NFE 是速度网络评估次数。三步/切片批不意味着整个体只执行三次网络：有多个 chunk 时，调用次数为 `3 × ceil(B*D/chunk_size)`。GPU batch并行处理切片，所以墙钟时间还依赖 chunk、尺寸、硬件和实现。

## 10. 你的十个工程问题，按当前代码回答

| 问题 | 当前代码可确认的答案 |
|---|---|
| t 的 shape | 展开切片后 `(B*N,)`；图像广播为四维 |
| time embedding | MONAI 内部正弦/余弦编码，再 MLP；输入时间没有乘 1000 |
| OCT 怎样输入 | OCT 是初始状态；网络接口未额外接原 OCT |
| concat/cross-attention | concat 是四小波通道，不是 OCT condition concat；默认不启用条件 cross-attention |
| x0 是谁 | OCT；x1 是 OCTA；不要套 DDPM 的 x0=clean 约定 |
| pixel/latent | 不是 VAE latent；wavelet 输入/输出，IDWT 后图像 ROI loss |
| solver 几步 | 默认三步，写在类里，命令行没有这个选项 |
| 训练/采样路径 | 训练配对插值；采样从 OCT 积分，不使用 GT；实际轨迹可能偏离插值线 |
| normalization | resize/crop后每个模态独立 min-max，且未加防零 epsilon |
| registration | 不执行、不检查；shape 相同不足以证明配准 |
