# 练习 04 的输出逐项解读，以及 f-string 语法

日期：2026-10-13。对应 [04_python_and_flowoct.py](../learning/04_python_and_flowoct.py)。

这个脚本用人工数据验证代码规则与数学关系，没有训练真实 FlowOCT。最后的 passed 表示写在练习中的检查符合预期。里面的 NaN 是故意用错误索引构造出来的现象。

## 1. message = f"{self.run_name}: step {self.steps}" 是什么

这是 Python 的格式化字符串，叫 f-string。字符串前面的 f 表示将花括号里的表达式结果填入文字。

假设 self.run_name 为 baseline、self.steps 为 2，则：

```python
message = f"{self.run_name}: step {self.steps}"
# 得到字符串 "baseline: step 2"
```

`{self.run_name}` 填入对象的实验名，`{self.steps}` 填入对象的步数，中间的 `: step ` 是普通文字。这个冒号在引号内、花括号外，没有定义函数或代码块的作用。[Python 官方 f-string 说明](https://docs.python.org/3.10/tutorial/inputoutput.html)

可以用更长的字符串拼接表达同样意思：

```python
message = self.run_name + ': step ' + str(self.steps)
```

步骤递增来自前一行 `self.steps += 1`，f-string 只是读取当前值并组织文字。

## 2. 第一组输出：同一个对象调用了两次方法

```text
baseline: step 1
baseline: step 2
Independent steps: 2 0
Local message stored on object: False
```

脚本依次调用 first.record_step() 与 Experiment.record_step(first)。两次调用中的 self 都是 first，所以其 steps 变成 2；second 没有调用，所以 steps 仍是 0。

`message = ...` 是方法里的局部变量；`self.steps = ...` 则是对象属性。hasattr(first,'message') 检查 first 有没有 message 属性，结果为 False。这是预期结果。return message 将字符串交给外部，print 把它显示出来，没有执行 self.message 赋值。

## 3. 第二组输出：两个体，每个抽两张，共四张切片

```text
Volume: (2,1,8,32,32)
Paired indices: [1,4]
Selected slices: (2,1,2,32,32)
Flattened batch: (4,1,32,32)
```

原数据 B=2、C=1、D=8、H=W=32。每个体抽两张，编号 1、4；索引从 0 开始，它们是第 2、第 5 张。

抽取后 B 和 C 不变，切片数变为 N=2。随后将体批量 B 与抽取数 N 合并，M=B×N=4，因此二维批量有四张单通道切片。OCT 与 OCTA 使用同一组编号，保持位置配对。

## 4. 第三组输出：时间广播与端点恒等式

```text
Time shapes: (4,) -> (4,1,1,1)
Exact-velocity endpoint max error: 5.960464477539063e-08
```

每张切片一个时间；变形后可沿该张图的通道、高、宽广播。网络时间输入使用 t，图像插值使用 t_img。

已知 x_t=(1-t)x₀+t x₁，以及理想速度 u=x₁-x₀，则 x_t+(1-t)u=x₁。这里用真实 OCTA 构造理想速度，验证这个公式。

`5.96e-08` 表示约 0.0000000596，是浮点数运算产生的很小误差；不是模型在真实数据上的预测误差。

## 5. 第四组输出：Euler 更新图像，优化器更新参数

```text
Three oracle Euler steps max error: 5.960464477539063e-08
Parameter gradient: 0.028065824881196022
Parameter update: 0.10000000149011612 -> 0.09719341993331909
```

三步演示每次给 OCT 加 u/3，总共加 u，理论上就到 OCTA。oracle 指演示中已知的理想速度；GT 是 ground truth，即真实目标。真实生成不能使用未知的 GT 来计算速度。

参数更新用的是一个可学习标量 weight 和简单 SGD。学习率为 0.1，所以：

```text
新参数 ≈ 0.1 - 0.1×0.0280658 ≈ 0.0971934
```

backward 计算梯度，step 使用梯度更新参数。这验证训练更新的机制，没有训练大型 U-Net。

## 6. 第五组输出：错误 ROI 与正确 ROI

```text
Wrong indexing shape: (0,8,32)
Wrong empty-ROI mean: nan
Correct indexing shape: (1,8,8)
ROI gradient: 0.03125
Outside-ROI gradient: 0.0
```

投影张量原形状为 `(1,32,32)`，轴是通道、高、宽。错误索引 `[4:12,3:11]` 把 4:12 用到长度为 1 的通道轴，取不到元素；第二轴取 8 行，第三轴全部保留，所以形状为 `(0,8,32)`。

空区域的均值无定义，得到 NaN，即 Not a Number。正确索引为 `[:,4:12,3:11]`，保留一个通道，取 8×8 像素，形状为 `(1,8,8)`。

本例损失是 64 个值为 1 的 ROI 像素的平方均值。对任一像素求导为 2×1/64=0.03125。区域外没有参与这一项损失，因此该项梯度为 0。

NumPy 数组只用于坐标分支；计算损失切的是原 pred 张量。故 detach 不妨碍这条原张量分支中的梯度。

## 7. 第六组输出：逐体投影和混合投影

```text
Per-volume projection: (2,1,32,32)
Original mixed projection: (1,32,32)
```

正确分组先恢复 `(B,N,C,H,W)`，再对每个体的 N 张切片取最大值；结果保留 B=2，两个体各有自己的投影。

直接沿展平后的 M=B×N 轴取最大值，会把两个体全部四张切片放在一起，最后只剩一张投影。做跨体的训练评价时，这个分组差异需要明确处理。

## 8. 第七组输出：正负候选数量决定对比损失

```text
Pairs: 1 logits: (2,1) loss: 0.0 fake feature gradient norm: 0.0
Pairs: 4 logits: (8,7) loss: 1.802487... fake feature gradient norm: 0.394598...
```

一对真假切片有两个特征，各自作为比较的起点（anchor）；每个 anchor 只有一个正候选，没有负候选。logits 为两行一列，正确候选概率为 1，所以交叉熵和特征梯度为 0。这个零来自候选数量，不代表模型预测完美。

四对切片有八个特征。每个 anchor 排除自己，另有一个正候选、六个负候选，共七个；所以 logits 为 `(8,7)`。

1.802487 是这组随机特征的对比损失；0.394598 是预测特征梯度的范数，即梯度整体大小。在这个例子里范数非零，表明损失提供了特征学习信号；不是 OCTA 的医学评价指标。
