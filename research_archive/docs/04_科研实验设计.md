# 如何自己动手设计 OCT→OCTA 科研实验

目标不是尽快堆出一个新模型名字，而是提出问题、控制变量、得到可解释的证据。你已经有 TransPro/MuTri/XOCT 相关环境，但本章不会声称它们已在当前目录跑通或已比较出优劣。

## 1. 先写一页研究问题

可作为第一版问题的表述：

> 在患者独立划分、相同数据几何与评价规则下，体上下文是否改善 OCT→OCTA 合成的跨切片结构保真？这种改善能否在计算预算受限时保持？

拆成三条可否定假设：

- H1：与仅单切片输入相比，邻层/邻B-scan上下文改善结构指标，而不只是背景主导的PSNR。
- H2：改善来自利用上下文，不完全来自参数增加、更多训练更新或分辨率差异。
- H3：用合理patch、overlap和低NFE，可以在明确预算内保留质量，且拼接误差可控。

要先说清“跨切片”是哪一个物理轴。增加沿扫描序列的上下文，与增加沿视网膜axial depth的上下文，含义不同。原体的数组轴没核对时，不应写“深度血管连续性”作为结论。

还要写失败标准：如果3D只提高全体PSNR，细血管结构没有改善，H1不成立；如果等参数/等预算2D也得到相同提升，H2不足；如果只有巨额预算获益，H3不足。科研可以得到否定结果。

## 2. 先冻结数据与评价，再改网络

建立manifest：patient_id、scan_id、FOV、split、路径、轴含义、spacing、配准状态、质量等级。原数据只读保存，转换版本独立管理。

患者级分组不是文件随机分割；不要让同一患者另一眼或随访进入测试。所有方法共享相同train/validation/test清单。多切片和多patch不能充当独立患者扩大统计样本数。

预处理需固定：空间网格、强度缩放、异常强度、resize策略、ROI、padding、augmentation、原分辨率或下采样。特别是小血管：下采样使它消失后，再好的3D模型也无法恢复患者特异性信息。

保留原尺度评价或至少统一物理尺度。不同FOV的同一像素宽度对应不同毫米长度，不能未经说明合并结构指标。

如果采用GT提供的解剖层边界做评价，应说明这是有GT的离线评价；部署时是否能得到同样的层边界，要另行设计。不能将GT边界当作无标注推理免费输入。

## 3. 基线应该怎样分组

不要一步把2D wavelet FM改成3D pixel FM，再把全部差异归功于3D。建议两个阶段：

### 阶段A：验证上下文的净作用

| ID | 表示 | 空间建模 | 源条件 | 目的 |
|---|---|---|---|---|
| A0 | pixel | 2D U-Net | 仅起点 | 共同简化FM基线 |
| A1 | pixel | 2.5D邻域→中心slice速度 | 仅起点 | 低成本上下文 |
| A2 | pixel | 3D patch U-Net | 仅起点 | 真实体邻域速度 |
| A3 | pixel | 更宽2D、参数量靠近A2 | 仅起点 | 排除主要容量解释 |

这组先用同一个基础速度MSE。时间、预处理、采样、优化器保持相同。为了避免仅MSE不公平地削弱某个结构，也可以另外加一个共享重建损失，前提是所有组一致。

### 阶段B：回到FlowOCT及论文设计

| ID | 变体 | 对照目的 |
|---|---|---|
| B0 | 公开FlowOCT，保留原实现协议 | 给领域baseline定位 |
| B0-fix | 只修投影索引，明确命名 | 保证ROI非空，分清bug与方法 |
| B1 | 3D pixel FM +源条件 | 对照条件作用，不能先声称新颖 |
| B2 | 3D wavelet FM，8带 | 分析频率表示；论文已提出3D DWT |
| B3 | 对最好基础模型加一个结构损失 | 验证针对具体错误的监督 |

公开代码与论文有差异时，至少报告“公开实现版”与“按论文补全版”的协议区别。不要把原代码的bug表现当成证明自己新结构有效的主要证据。

早期不用一次训练所有组。先让A0/A2在小规模pilot上可稳定训练，确认成本和评价，再展开。

## 4. 真正3D不是只改 spatial_dims

完整3D-FM路径：

\[
A,Y\in\mathbb R^{B\times1\times d\times h\times w},\quad
T\in\mathbb R^B,
\]

\[
X_T=(1-T)A+TY,\quad U=Y-A,\quad \hat U=V_\theta(X_T,T,A).
\]

实现变动需要同步：

| 模块 | 三维设计必须明确什么 |
|---|---|
| Dataset | 同步3D patch、物理轴、spacing、foreground采样规则 |
| 时间广播 | `(B,1,1,1,1)`；同一体patch内同一t |
| 网络 | Conv3d/U-Net下采样，保持空间匹配与skip |
| Wavelet | 不用wavelet时1通道；用完整3D时8带，可逆性测试 |
| 条件 | 每步源A怎么注入；concat/encoder/feature modulation分别定义 |
| Head | 如需3D embedding，明确Conv3d或带坐标slice encoder |
| Projection | 每患者沿真实解剖depth轴投影，不跨batch |
| ROI | GT/解剖规则，区别矩形bbox与血管mask |
| 推理 | 全体或sliding window；halo、overlap、融合与状态更新方式 |
| checkpoint | 完整训练状态、模型配置、精确恢复 |

三维训练依然对一个随机t做一次forward，成本主要来自网络激活，而不是每个样本积分数百步。`learning/03_minimal_3d_fm.py`展示了这些概念的最小版本。

## 5. 2.5D 怎样设计才算清楚

取相邻2k+1张配准slice，网络通过channel看到邻域，输出中心slice速度。要明确：中间状态是所有邻片共同插值还是只有中心状态加原OCT邻域；哪个t共享；边界如何padding；重组时每张中心只预测一次。

例如同一个训练patch内共享t，输入3张x_t邻片，输出中心u。这样能对比2D和邻域作用。若额外concat3张原OCT条件，输入变6通道，要单独命名与消融。

不要把“输入3张2D slice”叫完整3D卷积。它是可行的低成本对照，可能比昂贵3D更适合你的6GB机器。

## 6. 你的6GB显存怎样安排

从已验证的教学32³开始只解决代码问题。真实结构实验不要把全体resize成32³就宣称有效。

3D研究pilot可尝试小通道数、batch1、patch如16×64×64，或32×64×64，具体轴含义先确认。这些是待benchmark的候选，不是已测显存承诺。

优先：小patch/少通道、低分辨率attention、梯度累积（保持有效batch）、合适的activation checkpointing。AMP需要先修复/验证原自定义wavelet的dtype路径；不是打开autocast就保证可用。

测量 `torch.cuda.max_memory_allocated()`，并区分allocated/reserved与系统显存。失败时减patch，再看UNet下采样/GroupNorm条件。论文48GB硬件不应当作6GB模型尺寸参考。

预算有三个不同标准：相同optimizer updates、相同看到的有效体素/患者样本、相同墙钟训练时间。很难同时严格一致。主实验先确定一种，再补另一种效率对照，记录参数/FLOPs/时间。仅相同epochs无法保证公平，因为每轮采样的slice/patch数量不同。

## 7. 三维推理如何减少接缝

选overlap sliding window，例如50%作为起始候选；用非零归一化权重融合，确保每个体素至少被覆盖。边缘padding明确、移除halo，恢复原空间。

两种算法要区分：

1. 每patch独立积分到终点，再融合最终预测。
2. 每个时间步对全局当前状态切patch，预测并融合速度，再更新全体状态。

第二种更接近同一个全体状态上的速度场，第一种更简单但不同patch轨迹在边界可能不一致。不能把两者都笼统称为“3-step sliding window”而不说明。

固定权重同一体对不同overlap/patch边界测试，画接缝误差图。patch位置和裁剪本身是实验变量，不要只挑中间好看的区域。

## 8. 损失权重怎样节约调参时间

先基础loss稳定，再每次增加一种辅助项。

步骤：

1. 在固定pilot患者和batch上记录各原始loss及加权贡献。
2. 在共享速度网络上分别看辅助项与主项的梯度范数；同量级loss不等于同影响。
3. 选一个小范围的对数尺度，如λ∈{0.001,0.005,0.02}，其余设置不变。
4. 用固定更新步数的短pilot筛选候选，但保留一个中后期检查，避免早期排名误导。
5. 根据预设主验证指标选一组，再在足够训练预算下重复多个seed。
6. 完成敏感性曲线/消融；禁止从测试集选λ。

可以先让新辅助梯度约为主项的一小部分，再研究是否过强。这是工程启发，不是理论推导的最优系数。记录是比“凭经验试了很多组”更有价值的资产。

避免同时搜学习率、patch、模型宽度、所有loss系数和solver。即使算力足够，多变量变化也让结果难解释。

## 9. 评价必须回答你的假设

### 9.1 重建指标

固定range的全体MAE/PSNR/SSIM、预先冻结的前景/视网膜ROI重建。背景主导会掩盖结构问题；预测不能改变自己评分ROI。

LPIPS按2D切片/投影使用时记录灰度转通道、输入范围、backbone、采样位置与聚合。FID是分布指标，不是配对患者准确率；小样本/不同slice数可能影响统计。两个包在requirements里不代表作者公开了协议。

### 9.2 结构指标

有真血管标签时报告Dice/clDice/中心线召回等；没有标签时，固定一个独立分割模型或阈值协议产生pseudo-mask，并明确其局限。中心线/拓扑评价的毫米尺度、阈值和预处理必须一致。

同时报告漏检与多生成。例：precision=TP/(TP+FP)，recall=TP/(TP+FN)。clDice强调管状连通，但不能完全替代精度与假血管分析。

跨slice差分只测平滑会奖励模糊或全零。可比较与GT的梯度/中心线连续性差异，并结合强度与分割指标，不能只看预测自身变化小。

### 9.3 可靠性和下游

固定真实OCTA上训练且未见测试患者的分割/分类器，比较真实与合成输入的下游表现。记录训练患者、labels、分层统计。评估seen和unseen时必须解释是否曾参与分类器训练；不能将seen的成绩称为独立临床泛化。

合成看起来可信不等于患者的每条血管真实存在。这个问题需要患者配对结构与独立下游证据，而不仅是图像逼真指标。

## 10. 不确定性方向如何稳妥地做

如果从确定性源A积分同一个固定速度场，不引入随机变量，多次eval通常得到同一结果。要研究条件分布，可定义noise→target或noise→residual的条件FM，并持续输入A。

但随机源不自动代表真实患者多种可能。一个患者仅有单次OCTA监督时，不能充分识别该患者的完整条件分布。

最少要看：采样均值与单次结果的质量、方差是否预测错误、校准曲线、风险-覆盖曲线、异常/分布外样本、不同噪声种子和模型seed。比较简单ensemble/dropout等基线。不要用“方差漂亮”就声称减少幻觉。

这建议放第二阶段；第一篇实验先把数据与3D context作用弄清楚。

## 11. 最小有说服力的实验表

| 表/图 | 需要回答的问题 |
|---|---|
| 数据协议与几何表 | 患者数、FOV、轴/spacing、划分、预处理是什么 |
| A0/A1/A2/A3主结果 | context净作用是否存在、容量能否解释 |
| 固定权重NFE曲线 | 1/3/5/10次Euler预测的质量-时间权衡 |
| context/condition消融 | 只改变一项时作用多大 |
| 不同patch/overlap | 3D效果是否依赖拼接或感受野 |
| 多seed和患者配对CI | 差异是否稳定、患者间变异有多大 |
| 随机患者与失败病例图 | 错误发生在哪里、是否有多生成 |

以患者为单位计算配对差值与bootstrap置信区间；多随机seed是训练稳定性，不等于增加独立患者。固定同一组seed训练对照，并同时汇报患者变化与seed变化。必要时按疾病/FOV/质量分层，样本很少时不作强结论。

## 12. 从学习项目变成自己的项目

建议在独立目录组织：

```text
my_oct_flow/
├── configs/           每个实验不可变配置
├── data/              manifest、paired_loader、同步patch
├── models/            2D/2.5D/3D速度网络、condition模块
├── losses/            基础FM与明确的辅助监督
├── engine/            训练步、验证、完整checkpoint
├── inference/         solver、sliding_window、融合
├── evaluation/        frozen指标规则、按患者汇总
├── scripts/           可复用的训练/测试入口
└── runs/              配置、版本、日志、预测与报告
```

这是建议结构，不是已经替你实现完整科研系统。先保持简单：data/model/train/evaluate四部分即可，随着需求增加再拆。

每次实验前复制 `experiment_templates/run_record.md` 并填写假设、唯一变量、预算、选择规则。实验后写支持/不支持哪些假设，并保留失败结果。

你真正独立的标志不是不再问问题，而是能说明：为什么这一步值得试、成功该出现什么变化、失败又排除了什么解释。
