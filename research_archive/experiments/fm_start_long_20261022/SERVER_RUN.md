# 三组从2400继续到7200次

服务器：`research-server.example.org`，物理GPU0。

目录：`/srv/oct_research/fm_start_long_20261022`。

这是对上一轮匹配单块实验的延长，检验原FM是否只是学习更慢。三组都沿用相同10301固定体块、网络、共同原始初始化和原有时间采样方式。依次让三组达到4800，再达到7200次成功更新。

- `fm_uniform`：每次均匀随机t；正常推理Euler8。
- `direct_t0`：每次固定t=0；正常推理单步。
- `fm_half_start`：一半t=0、一半均匀随机t；正常推理Euler8。

模型、AdamW优化器动量/二阶矩、AMP scaler都从原2400次断点恢复；学习率2e-4不变。7200项时间序列的前2400项与原实验逐元素相同。不会改写原实验目录。

| 内容 | 位置 |
|---|---|
| 恢复协议与初始断点哈希 | `protocol.json` |
| 原2400次断点副本 | `seeds/` |
| 预先冻结的完整时间序列 | `schedule.npz` |
| 4800次三组结果 | `stage_4800/<组名>/` |
| 7200次三组结果 | `stage_7200/<组名>/` |
| 运行状态和日志 | `status.json`、`run.log` |
| 所有4800/7200结果审计 | `final_audit.json`、`verification.json` |

每个结果目录保留该阶段的训练记录、每400次生成评价、检查点和八个体块的三维预测。原2400次结果与输入保留在 `/srv/oct_research/fm_start_control_20261022`。

这仍是单体块、单种子诊断，只有两位原验证患者。延长训练可以判断有限预算内的拟合效率，不能证明收敛极限或新患者泛化。
