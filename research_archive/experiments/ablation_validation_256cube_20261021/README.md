# 256³ 同病例小样本验证

独立于此前 64×64 横向体块实验。原五组、FlowOCT 及旧训练文件均保留。

**六组均已完成，各400次更新；35份预测审计通过。** 先看[本轮结论](reports/CONCLUSIONS.md)。

[查看逐组更新的试跑报告](reports/index.html)，[视野范围示意](reports/field_of_view.png)。未完成组不会进入结果表。

- 固定训练病例 NORMAL 10301；验证仍为 10319、10447、10456、10302。测试集不参与。
- 中央 `[Z,Y,X]=[256,256,256]`，保留全部预处理 Z；从原始横向网格直接裁剪，不缩放、不逐例 minmax、不增强。
- 每例只取一个中央块，单病例阶段各组从头训练，seed20261021，预设 400 次成功更新。
- 原五组保持 base16、各自表示与损失、AdamW2e-4、AMP、clip1、八步生成。
- 增加网络块和自由积分步骤的梯度检查点，重算减少显存；输出、完整八步损失和参数梯度先与原实现核对。
- FlowOCT 保留二维网络与四项损失，FP32、Adam、原生 D//4 抽片；256³ 输入每次抽64片，网络按8片重算，InfoNCE及投影仍使用全部64片。
- FlowOCT 同时导出原生三步与统一八步推理；各组均按纯 OCT 自由生成评估。

FlowOCT按每片独立采样时间；通用步骤日志`time`只记录未使用的3D参考标量，详见[时间字段说明](06_flowoct/one_case/TIME_LOG_NOTE.md)。

中央256视野仍是整幅304视野的局部。报告将按原生256像素保存投影，并对相同物理64×64区域另行比较；不同视野的分数不能直接当作尺寸收益。
这是单种子的短程试跑，不能代替完整训练或泛化评估。

服务器目录：`/srv/oct_research/fm3d_validation_256cube_20261021`，仅使用 GPU0。
先 `bash benchmark256.sh`，全部通过后 `bash launch256.sh`。大体积权重和三维预测留在服务器；本地同步指标、日志与图片。
