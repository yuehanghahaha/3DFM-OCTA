## 两个独立阶段

1. `one_case`：10301 的一块 `[256,64,64]` 体块，从头训练 400 次成功更新，检查固定训练块记忆能力。
2. `few_case`：4 个训练病例、每例 2 块，从头训练 800 次成功更新；每例约 200 次、每块约 100 次。

两阶段不互相继承权重，避免把只针对正常病例预热的影响混入四病例实验。
每 200 次成功更新评估一次；AMP 溢出则重试同一病例/时间，不扣除成功更新预算。
这是首次固定预算检查；若 400/800 次尚未收敛，结论只能是该预算下表现不足，不能据此宣布模块无效。

病例在原始固定划分内，按疾病分层取编号最小的病例，不按质量或模型效果挑选：

| 疾病 | 训练 | 验证 |
|---|---|---|
| NORMAL | 10301 | 10319 |
| DR | 10304 | 10447 |
| AMD | 10310 | 10456 |
| CNV | 10439 | 10302 |

每例固定取 `origin_ZYX=(0,64,64)` 和 `(0,120,120)`；单病例阶段只训练前一块。
Z 使用完整的预处理深度 256；不依据 OCTA 或层标签挑位置。强度保持固定除以 255，禁止逐例 min-max。

## 严格保持的共同设置

- 同一 3D U-Net 架构、base16、固定 OCT 条件、batch1、AdamW、学习率 2e-4、weight decay=0、梯度裁剪 1、AMP。
- 同一物理体块、样本顺序、均匀时间序列、成功更新次数、8 步 Euler 推理和评价代码。
- 同一初始化种子。相同表示的各组初始权重相同；体素和小波的输入/输出通道不同，参数量及实际网络网格不同。
- 小波对完整体块做一次可微正交 3D Haar 变换，保留全部八个子带，系数不裁剪；生成后逆变换回体素。
- 单随机种子用于本轮可行性检查；足够训练之后还需要至少三个种子和完整验证集来评估稳健性。

## 损失具体作用在哪里

令 `c=OCT, y=OCTA`，`R` 为恒等映射或完整 3D Haar：

```text
cR = R(c), yR = R(y)
t ~ Uniform[0,1)
xt = (1-t)*cR + t*yR
L_FM = MSE(v(xt,t,cR), yR-cR)

s0 = cR
sj+1 = sj + v(sj,j/8,cR)/8, j=0..7
y_generated = inverse_R(s8)

Pz(a) = mean(a, dim=Z)
L_z = L1(Pz(y_generated), Pz(y))
L_reconstruction = L1(y_generated, y)
L_total = L_FM + lambda_z*L_z + lambda_rec*L_reconstruction
```

**投影和重建分支使用仅由 OCT 自由积分 8 步得到的结果，并对全部积分步反传。**
OCTA 只出现在 FM 标准训练状态和各损失的监督目标中，不被传入自由生成分支。
训练时生成体不裁剪，防止丢失越界梯度；评估时只在最后裁剪到 `[0,1]`。

与旧 `fm3d.train_projection` 的区别：旧入口投影约束只监督 `c+v(c,0,c)` 的单步估计，且默认横向块 96。
本轮五组统一为 64，投影约束作用在 8 步自由生成终点；旧实验不能直接作为这次第三组的对照。
本轮仍保留原始均匀 FM 时间采样，不额外加入 t=0 混合采样或更换噪声路径，以控制变量。
FM 依据 [原始论文](https://arxiv.org/abs/2210.02747)；非高斯源的配对路径可参考 [广义 CFM](https://arxiv.org/abs/2302.00482)。
本轮附加损失及权重是待验证设计，不是这两篇论文对 OCTA 效果的保证。

## 看什么结果

主要查看训练与验证患者的 **ILM–OPL 最大投影 PCC/SSIM**、血管区 MAE 和固定窗图片，辅以 Z 均值投影、B-scan、整体 3D MAE/PSNR。
同一病例先平均两个体块，再按患者等权汇总，不能把体块当独立患者。
层投影用与原项目相同的原生 640 深度坐标映射规则；层标签只用于事后评估。

模型开发按验证 ILM–OPL SSIM 保存 `best_validation.pt`，同时保留 `latest.pt`。
主表比较相同训练预算的 `latest.pt`，避免不等更新次数造成误判。
阈值 Dice/clDice 是投影的透明代理指标，不代表真实三维拓扑恢复。
每组保存初始指标、分项损失、逐例/逐患者指标、输入哈希、模型与优化器状态以及固定窗 PNG/预测 NPZ。

归因关系：03−01 和 04−02 是投影贡献；02−01 和 04−03 是小波贡献；05−04 是图像重建贡献。
固定小样本预算不能证明泛化有效。若训练病例仍失败，继续诊断目标/优化/容量；若训练明显改善但验证失败，再重点分析泛化。

## 运行

已冻结的数据和配置可直接复制到服务器，不需要再次随机选病例或搬运完整数据集。
`source/fm3d` 为五个所需模块的独立快照，文件哈希见 `source/snapshot.json`。
没有新增第三方依赖；沿用现有训练环境中的 torch、numpy、Pillow、scipy 和 scikit-image。

```bash
# 在服务器这个实验文件夹中；本轮使用物理 GPU0
GPU=0 bash run_all.sh

# 单独启动或恢复某一组 / 某阶段
python run.py --arm 04_fm3d_wavelet_zproj --stage few_case --resume
python report.py
```

`run_all.sh` 先运行真实梯度/保存恢复检查和显存基准，之后依次完成五组单病例、五组四病例实验。
配置、代码或缓存体块哈希改变会拒绝直接续训；改协议应新建运行版本。
每次评估为恢复点；进程中断后从最近一次评估的权重/优化器继续，未保存区间会重算。
查看 `status.json`、`logs/one_case.log`、`logs/few_case.log` 和各组的 `history.jsonl`。
最终打开 `reports/index.html` 或 `reports/RESULTS.md`；`summary.csv` 可用于汇总。

本地当前为报告镜像，不含大体积 `.pt` 和三维预测 `.npz`；恢复训练请在服务器原目录执行。
若需本地恢复，先按 `server_artifacts.json` 取回对应检查点，并保持训练代码、配置及冻结数据一致。
两个阶段的预算不同，跨阶段差异不能单独解释成病例数量的影响；本轮体块指标也不能与此前 50 例整卷测试指标直接比较。
