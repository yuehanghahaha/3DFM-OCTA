# 3DFM 第90轮模型：验证集推理

2026-10-20，使用服务器0号3090完成10例验证集推理。模型为
`runs/fm3d_3M_run01/best.pt`，已核实checkpoint epoch为90。
保持256×64×64滑窗、50%重叠、8步Euler、AMP和完整预处理体评价。
本次没有评估测试集，没有修改模型、权重或训练规则。

## 结果

| 输出 | 患者宏平均MAE↓ | 患者宏平均PSNR↑ |
|---|---:|---:|
| 第90轮模型 | 0.0136997546 | 28.1024173 dB |
| 全零输出诊断参照 | 0.0212204762 | 24.3960772 dB |

模型指标与训练时第90轮验证记录一致。相比全零输出，MAE下降约35.4%，
PSNR提高约3.71 dB；全零输出仅用于诊断，不是正式对比方法。

10例投影总览均显示血管对比度和细节恢复不足。抽查10302、10447、10495
的三个固定位置B-scan，预测能呈现层状轮廓，但缺少真实OCTA中的亮点和局部纹理。
10495即使PSNR达到33.034 dB，血管投影仍明显不足。因此整体MAE、PSNR
不足以代表血管结构恢复质量。

逐病例平均后，预测体平均强度0.014139，真实体0.021220，前者约为后者66.6%。
这不是每个病例都整体偏暗：例如10447预测平均强度高于真实体，但血管对比度仍弱。
全深度Z均值投影的Pearson相关系数逐病例平均约0.259，
范围0.156–0.351；它是补充诊断量，不是血管分割或拓扑指标。

所有比较图使用相同显示窗口，无逐图归一化。投影为全深度均值，
并非视网膜分层投影；面板显示比例不代表物理比例。

## 建议

先保留本次结果作为初始基线。下一步优先核验配对、归一化与推理路径，
并做少量训练病例的拟合诊断，区分训练样本本身拟合不足与泛化问题。
若训练病例也无法恢复血管，应先检查实现和优化；若训练病例明显好于验证，
再重点研究泛化。不要仅凭当前日志断言是网络容量不足或增加轮数即可解决。
后续再以受控实验评估采样、损失或模型改动，避免同时改变多项。

## 复现命令（输出目录必须尚不存在或为空）

```bash
cd /srv/oct_research/fm3d_ubuntu
source /opt/conda/etc/profile.d/conda.sh
conda activate /srv/oct_research/conda_envs/lyh_fm3d
CUDA_VISIBLE_DEVICES=0 OMP_NUM_THREADS=4 MKL_NUM_THREADS=4 python -u -m fm3d.evaluate \
  --checkpoint runs/fm3d_3M_run01/best.pt \
  --split validation \
  --ode-steps 8 \
  --device cuda \
  --output runs/fm3d_3M_run01_val_repeat
python -m fm3d.visualize \
  --input runs/fm3d_3M_run01_val_repeat \
  --output runs/fm3d_3M_run01_val_repeat_report
```

预测NPZ内`octa`为生成体，`octa_gt`为真实体，轴顺序为ZYX。
OCTA真值仅用于评价，不输入生成函数。可视化程序仅读取结果，不重新推理。
